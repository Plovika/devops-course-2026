# SVN vs Git

**1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?**
В Git ветка — это просто ссылка (указатель) на конкретный коммит. Создать её — мгновенно и не требует места.
В SVN ветка — это копирование всей структуры папок проекта на сервере. Это долго и занимает много места.

**2. Можно ли в SVN сделать коммит без интернета? Почему?**
Нет, нельзя. SVN — централизованная система. Все коммиты отправляются на один общий сервер. Без интернета связи с сервером нет — коммит не пройдёт.

**3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?**
- В больших старых (legacy) проектах, где уже всё настроено под SVN.
- В госсекторе и банках, где важна строгая централизация и контроль доступа.
- Если команда не хочет разбираться с распределённой моделью Git.
